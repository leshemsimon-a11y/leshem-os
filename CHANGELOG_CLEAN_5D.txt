inspector detail sections, and legacy panels are all collapsed by default.

Design → concept cards, Brief → output/render brief). Production is an honest
disabled future step. On narrow viewports the grid collapses to one column and
the rail becomes a horizontal strip (mobile-future-safe; mobile NOT built).


WHAT WAS PRESERVED
------------------
All business logic stayed inside the existing panels — the shell only arranges
them. Concretely:
  • product/style/metal selection, stone-led + metal-only — DesignConceptPanel direction view
  • concept generation, select, remove (calm inline confirm), refresh-one — DesignConceptPanel (5B.3), unchanged
  • output generation + structured render brief + client desc/materials/notes/
    assumptions/next steps — DesignOutputPanel (5B + 5C), unchanged
  • Work Tray / Active Work sync — unchanged store calls
Verified by re-running the 5B.3 and 5C logic sandboxes after the refactor:
  5B.3 concept-controls sandbox: 17/17 pass
  5C structured-render-brief sandbox: 16/16 pass


HOW STALE WARNINGS WERE PRESERVED
---------------------------------
The shell calls the SAME helpers — conceptsAreStale() and outputIsStale() from
designDraft.js (byte-identical to baseline; the four stale functions were
content-hashed and confirmed unchanged). It surfaces two independent, calm,
visual banners at shell level:
  • concepts stale  → "הבחירות השתנו" + "עדכן כיוונים"
  • output stale    → "הפלט מבוסס על כיוון קודם" + "עדכן פלט"
Both can show together. The command-bar status dot also reflects output state
(ready = gold, stale = ice-blue). A 6/6 shell-state sandbox confirmed the
mapping fires on product/style/metal/stone/concept change.


HOW CONCEPT CONTROLS WERE PRESERVED
-----------------------------------
The concept cards are still rendered by DesignConceptPanel (view="concepts")
inside the canvas. Select / refresh-one / remove-with-confirm are the exact
5B.3 handlers — untouched. The bottom strip's variant chips call the same
briefStore.selectConcept() the cards use, so selection is one source of truth.
