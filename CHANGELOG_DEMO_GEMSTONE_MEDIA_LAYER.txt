WHAT I BUILT
----------------
1. Copied the media pack as-is into public/demo-media/gemstones/ — same
   folder names, same filenames as supplied (box-view/, tweezer-view/,
   demo-gemstone-assets.json). Already-optimized WEBP (36 files, 928KB
   total) — no re-encoding needed this time.
2. NEW lib/studio/demoGemstoneAssets.js — the supplied
   src/data/demoGemstoneAssets.ts adapted to plain JavaScript (this project
   uses no TypeScript) and relocated to lib/studio/ to match where
   labels.js and assetPack.js already live (per "adapt it to the existing
   project structure"). Content/schema is identical to your JSON manifest.
   Every record keeps its original `temporaryOnly: true` flag exactly as
   supplied. Includes:
     • the provided `findDemoGemstoneAsset()` helper, adapted 1:1 (matches
       by canonical English variety/shape — ready for future use once a
       screen has canonical fields available)
     • one small additional helper, `getGemstoneThumbFallback(item, view)`
       — matches the Design Studio's existing Hebrew display text
       (shapeHe/stoneTypeHe, the same fields StudioStoneStrip.js already
       reads for the chip title) using the same keyword-matching pattern
       already used by lib/studio/assetPack.js from the previous milestone.
       Pure function, no store access, no mutation.
3. StudioStoneStrip.js — when a tray item has NO real snapshot.primaryImage,
   the chip now tries, in order:
     a. a matching box-view demo photo from THIS pack (richer variety —
        diamond round/pear/emerald-cut/cushion, sapphire, emerald, ruby,
        paraiba tourmaline)
     b. if no match, the existing fallback from the previous Starter Asset
        Pack v1 (unchanged, e.g. its own oval-diamond photo, which this new
        pack doesn't include in box-view)
     c. if neither matches, the original generic line-icon — exactly as
        before, zero regression
   The small gold "אילוסטרציה" (illustration) marker from the previous
   milestone is reused as-is — no new label needed, no existing label
   touched.
