LESHEM.S OS — Clean 5D-R — Studio UI Reset to North Star
========================================================

Root-ready bundle. Upload the CONTENTS of this folder to GitHub at the same
paths. A STRUCTURAL visual reset of the Design Studio shell to the approved
North Star. No business logic changed. No feature expansion.

Baseline preserved: 5B.3 logic + 5C render brief / "Create Jewelry From Stones"
+ 5D functional shell wiring.


WHAT VISUAL DIRECTION WAS REJECTED
----------------------------------
The previous 5D.1 look was a NARROW 960px CENTERED COLUMN with charcoal panels
floating in large empty side margins — it read like an admin page, not a studio.
Root cause: the outer app shell wraps content in
  desktopContentWrap { maxWidth: 960px; margin: 0 auto; padding: 48px 40px 80px }
so the Design Studio could never fill the viewport. That centered-page direction
is rejected and replaced.


WHAT WAS REBUILT (North Star)
-----------------------------
A FULL-VIEWPORT studio workstation that fills the area beside the app nav rail:

  ┌───────────────────────────────────────────────────────────┐
  │ command bar      │ selected-stones strip (thumbnail chips) │  ← compact top
  ├──────┬──────────────────────────────────┬─────────────────┤
  │ RAIL │ CENTRAL CANVAS (dominant)         │ INSPECTOR (≈340)│
  │ 76px │  selected → SPLIT:               │ icon rows +     │
  │ icon │   left = jewelry preview         │ collapsed       │
  │ steps│   right = CAD/blueprint sketch   │ disclosures +   │
  │      │  else → 3 concept cards          │ pinned gold CTA │
  ├──────┴──────────────────────────────────┴─────────────────┤
  │ BOTTOM STRIP — variant thumbnails + primary CTA            │  ← compact
  └───────────────────────────────────────────────────────────┘

Key moves:
  • Scoped full-bleed: an additive `fullBleed` prop on the OUTER shell
    (components/studio/shell/StudioShell.js) makes ONLY /studio/design render
    edge-to-edge (height:100vh, no centered column). Every other studio page
    keeps the 960px centered column unchanged — verified none set fullBleed.
  • Full-height regions with internal scroll (true app feel). Safe fallbacks:
    on short viewports the shell switches to page scroll; on narrow widths the
    middle grid stacks and the rail becomes horizontal. Mobile not built, not blocked.
  • Central canvas is dominant: when a direction is selected it shows the
    North-Star SPLIT — a jewelry preview (inline CSS/SVG jewel mark, no asset,
    no render generation) beside a CAD/blueprint sketch. No real render is
    produced (out of scope); the preview is a styled placeholder.
  • Inspector drawer: 4–6 compact icon rows + closed-by-default disclosures
    (Design Logic / Stone Usage / Materials / Production / Assumptions / Next),
    with the soft-gold "הכן בריף הדמיה" CTA pinned at the bottom.
  • Stone strip: thumbnail/chip style with an "+" add affordance (opens the
    existing AssetPicker); one/many/parcel/metal-only states.
  • Text reduced aggressively: icons, chips, thumbnails, short labels, drawers.

WHAT LOGIC WAS PRESERVED
------------------------
All business logic lives in the existing panels/stores and was NOT touched. The
shell only arranges regions and threads them via the same props + brief store:
  • concept generation, select, remove-with-confirm, refresh-one — DesignConceptPanel (5B.3)
  • output + structured render brief (Hebrew labels, English copy prompt) — DesignOutputPanel (5B + 5C)
  • stale warnings — SAME conceptsAreStale / outputIsStale helpers
  • stone-based + metal-only workflows; Work Tray / Active Work sync
Proof:
  • designConcepts.js byte-identical to baseline.
  • The four stale functions content-hashed → UNCHANGED.
  • Logic sandboxes re-run after the reset: 17/17 (5B.3) + 16/16 (5C) + 6/6 (shell state).


HOW STALE WARNINGS WERE PRESERVED
---------------------------------
The shell calls the unchanged conceptsAreStale() / outputIsStale() and surfaces
two calm, slim banners above the canvas (concepts = gold, output = ice-blue),
each with its update action. The command-bar status pill also reflects output
state (ready = gold, stale = ice). Independent — both can show together.


HOW CONCEPT CONTROLS WERE PRESERVED
-----------------------------------
Concept cards are still rendered by DesignConceptPanel (view="concepts") inside
the canvas. Select / refresh-one / remove-with-confirm are the exact 5B.3
handlers — untouched. The bottom-strip variant chips call the same
briefStore.selectConcept() the cards use (single source of truth).
